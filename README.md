# 記事印象調査 — 試用版

短い架空の記事を読み、受けた印象を回答するアンケートの試用版です。Google Apps Scriptを使い、条件のバランスを保って108篇から27篇を抽出し、回答をGoogleスプレッドシートに保存します。

**現在の108篇は動作確認用のデモ例文です。グループで選定した最終版の108篇ではありません。質問文も検討中です。**

## どのように抽出するか

- 108篇 =「正義 × 嫉妬 × 性的」の27条件 × 2類型（金銭・不倫）× 各2篇。
- 回答者1人につき27篇を抽出し、27条件を1篇ずつ提示します。各軸の「大・中・小」はそれぞれ9篇です。
- 金銭・不倫は13篇／14篇で、各類型の内部でも各軸の水準が4篇または5篇になるようにします。
- **4人で1区組**を構成し、108篇を区組内で1回ずつ割り当てます。区組ごとに割り当てを作り直し、各回答者の提示順もランダムにします。
- 同じブラウザで再開した場合は、記事と順序を維持します。

完全に独立した無制約のランダム抽出ではなく、条件のバランスを保つ方式です。均等になるのは「割り当て数」であり、途中離脱があると「完了回答数」は均等になりません。この設計も試用時の検討対象です。

## 現在の質問

各記事について、次の3問に1〜7で回答します。

1. この人物の行為を、どの程度許せないと感じますか。
2. この人物は、経済的に恵まれていると思いますか。
3. この記事を読んで、身体的に親密な場面がどの程度思い浮かびましたか。

2問目は経済的な恵まれ方の評価、3問目は親密な場面の想起を尋ねています。嫉妬感や性的興奮そのものを測ると確定した尺度ではありません。

## 試用とデータ保存

グループ内の試用URLは別途共有しています。現在の試用ページは指定されたGoogleアカウントでログインして利用します。スマートフォンで開けない場合は、Google のログイン中のアカウントを確認してください。

Google Apps Script版では、回答を管理者の**非公開のGoogleスプレッドシート**に保存します。完了時に `Responses` シートへ1人81行（27篇 × 3問）を記録し、`Sessions` シートには途中経過も保存します。フォーム上で氏名・メールアドレスは入力させず、コード内でもGoogleアカウントのメールアドレスを取得・記録していません。

この公開リポジトリに含まれるのはプログラム・デモ例文・テスト・説明です。実際の回答データや回答表へのリンクは含めていません。

技術的な確認をする場合は、Node.js 26以降の環境で次を実行できます。

```sh
npm ci
npm test
npm start
```

`http://127.0.0.1:4178` でローカル版を開けます。ローカル版の回答はそのブラウザ内だけに保存され、Googleには送信されません。

## 確認状況

- 自動テストで1,000人分の条件バランス、重複の防止、再開、保存失敗からの再試行などを確認しています。
- Google上の試用版では、Safariで27篇・81項目の提出と保存を確認しました。スマートフォンでも指定アカウントでページが開くことを確認済みです。
- 現時点ではグループ内試用向けです。本調査前に、最終例文・質問文・研究説明・同意手続き・参加者のアクセス範囲を確定する必要があります。
