# 記事印象調査 — 54件版

全員に54件を提示します。金銭／不倫 × 正義・嫉妬・性的の各3水準（計54条件）から各1件を抽出します。108候補がある場合は各条件の2候補からランダムに1件を選びます。記事の順序と、記事ごとの評価質問の順序を回答者ごとにランダム化します。Q1（続きを読みたいか）は必ず先頭に固定し、その後のQ2の3項目だけを回答者ごとにランダム化します。Q2の順序は同じ回答者の中では固定し、1〜7の選択肢は昇順です。開始後の最初のページで性別（女・男・その他の自由記述）を一度入力します。

同梱の本文は動作確認用にプログラムで生成する架空のデモ文章です。実際の回答データ、参加者情報、運用中のシート・デプロイのURLやIDは含みません。

## Googleスプレッドシートで変更する

| シート | 編集する場所 |
| --- | --- |
| Stimuli | `text`＝記事本文。`category`、`justice`、`envy`、`sexual`＝条件ラベル |
| Questions | `label`＝質問文、`low`／`high`＝7件法では1点／7点の説明、二択では0／1の選択肢、`enabled`＝使用する質問にチェック、`type`＝binary／likert7、`block`＝Q1（先頭固定）／Q2（順序ランダム） |
| Settings | `title`＝画面タイトル、`intro`＝開始画面の説明、`demo`＝記録に付ける試用フラグ（画面上の試用表示は非表示）、`accepting_responses`＝新規開始を受け付けるか |

変更後に新しく始めた回答へ反映されます。コードの再デプロイは不要です。開始済みの回答では、開始時の本文・質問・順序を保持します。新しいブラウザプロファイルなど、既存の作答記録がない環境から開始すると変更を確認できます。画面には試用ラベルや再開始ボタンを表示しません。

編集中は Settings の `accepting_responses` を FALSE にし、編集後に TRUE に戻してください。開始済みの回答はその間も継続できます。列名とIDは維持してください。質問を追加する場合は新しい一意のIDを付け、enabled に TRUE を入れます。有効な質問は1〜12件です。

文章は54件（各条件1件）、または108件（各条件2件）を登録できます。現在の108候補はそのまま使えます。形式・件数は開始時に確認します。本文の内容が条件ラベルに合っているかは別途確認してください。

## 保存するデータ

`Sessions` は進行状況と開始時の本文・質問の記録です。長いデータは複数セルに分割しています。`Responses` は完了済み回答で、1行が「1人×1記事×1問」です。現在の4問では1人216行になります。Q1のratingは1＝読みたい、0＝読みたくないです。Q2は1〜7です。記事順、質問順、本文、質問文、両端の説明、版識別子も保存します。

端末内には選択直後に下書きを保存します。記事の移動はサーバーの応答を待たず、即時に行います。回答はバックグラウンドで順番に同期し、同期中の変更は最新状態へまとめます。通信失敗時には同じ要求IDで再試行します。同期完了時は「保存済み」を1か所に表示し、失敗時は再試行の案内を表示します。「保存して休憩する」と最終提出はサーバーの確認を待ちます。未同期のまま閉じた場合は、同じ端末・ブラウザで再開すると下書きから同期を続けます。

`Analysis` は提出済みの `Responses` から作成する分析用の表です。列は participant_id（P0001形式の短いID）、stimulus_id、question_id、rating、version、gender の6列だけです。提出が確定するたびに更新します。原始記録は変更しません。`Participants` に短いIDと元のIDの対応、性別と自由記述を保存します。旧版で性別を尋ねていなかった回答は空欄のままです。`Questions_previous` は更新前の質問表の控えです。変更前後で意味が異なる質問には異なるIDを使います。

## 開発・設置

`npm ci`、`npm test`、`npm start` の順に実行します。ローカルプレビューはポート4180です。

`npm run build` で `apps-script/` と `dist/` を生成します。設置手順は [docs/SETUP.md](docs/SETUP.md) を参照してください。シートIDはスクリプトプロパティ `STUDY_108_SHEET_ID` に保存し、コードに埋め込みません。プロパティ名の108は以前の版との互換性のため残しています。

バージョンを固定したデプロイは、エディタの変更だけでは切り替わりません。[Googleのデプロイ説明](https://developers.google.com/apps-script/concepts/deployments)

自動テストは54件の層別抽出、条件件数、両方の順序のランダム化、表の編集と既存記録の保持、途中保存・再開、216行の提出、失敗時の再試行を確認します。

## 主なファイル

- `src/app.js`：画面、説明文、性別入力、作答と送信
- `src/core.js`：条件検証、54件の抽出、Q1固定・Q2ランダム化
- `src/sync.js`：ブラウザの下書き保存とバックグラウンド同期
- `src/Code.gs`：設定シート、回答保存、短縮IDと分析表
- `src/demo-bank.js`：架空のデモ文章生成
- `tests/`：模擬データを使う自動テスト
